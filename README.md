# Educação_Financeira_nas_Escolas_Públicas
Projeto acadêmico desenvolvido no curso de Sistemas de Informação da UNINASSAU, com foco na educação financeira nas escolas públicas. A iniciativa busca promover conhecimentos sobre planejamento financeiro, consumo consciente, organização de gastos e tomada de decisões, utilizando a tecnologia como ferramenta de apoio à aprendizagem.
